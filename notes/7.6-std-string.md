# Module 7.6 – `std::string`

### Learning Goals

- Understand what `std::string` is
- Learn how it replaces C-style strings
- Understand how strings manage memory strings
- Learn how to create, modify, and access strings
- Understand the relationship between `std::string` and `char*`

---

## The Core Idea

`std::string` is the **C++ standard string class**.

Example:

```cpp
std::string s = "hello";
```

Unlike C strings:

```c
char* s = "hello";
```

`std::string` manages:

- memory allocation
- resizing
- copying
- destruction

automatically.

---

## Why C Strings are problematic

In C, strings are just **arrays of characters terminates by `\0`**.

Example:

```c
char s[] = "hello";
```

Memory:

```
h e l l o \0
```

Problems with C strings:

- no automatic resizing
- buffer overflow risks
- manual memory management
- awkward APIs (`strcpy`, `strcat`, etc.)

Example bug:

```c
char buf[10];
strcpy(buf, "this string is too long");
```

Buffer overflow.

---

## `std::string` solves these problems

Example:

```cpp
std::string s = "hello";
```

Memory model (conceptually):

```
string object
   |
   V
heap memory

h e l l o
```

The string automatically manages its internal buffer.

---

## Creating Strings

#### From a literal

```cpp
std::string s = "hello";
```

#### Empty string

```cpp
std::string s;
```

Result:

```
""
```

#### Repeated characters

```cpp
std::string s(5, 'a');
```

Result:

```
"aaaaa"
```

---

## String Size

```cpp
s.size()
```

Example:

```cpp
std::string s = "hello";

std::cout << s.size();
```

Output:

```
5
```

Note:

> `size` does NOT include '`\0`'

---

## Accessing Characters

#### Index access

```cpp
s[0]
s[1]
```

Example:

```cpp
std::string s = "hello";

std::cout << s[1];
```

Output:

```
e
```

#### Safe access

```cpp
s.at(1)
```

Difference:

- `s[1]` → no bounds check
- `s.at(1)` → throws exception if invalid

---

## Modifying Strings

#### Append text

```cpp
std::string s = "hello";

s += " world";
```

Result:

```
"hello world"
```

#### Append another string

```cpp
std::string a = "hello";
std::string b = "world";

a += b;
```

Result:

```
"helloworld"
```

---

## String Concatenation

```cpp
std::string s = "hello" + std::string(" world");
```

Result:

```
"hello world"
```

---

## Iterating Over Characters

#### Range-based loop

```cpp
std::string s = "hello";

for (char c : s) {
    std::cout << c;
}
```

Output:

```
hello
```

#### Modifying characters

```cpp
for (char& c : s) {
    c = std::toupper(c);
}
```

Result:

```
HELLO
```

## `std::string` and `char*`

Sometimes we still need a C-style string.

Example: *interacting with C APIs*.

Use: 

```cpp
s.c_str()
```

Example:

```cpp
std::string s = "hello";

printf("%s\n", s.c_str());
```

`c_str()` returns:

```
const char*
```

Pointing to a null-terminated buffer.

---

## String Comparison

Strings can be compared directly.

Example:

```cpp
std::string a = "apple";
std::string b = "banana";

if (a < b) {
    std::cout << "apple comes first";
}
```

This performs **lexicographic comparison**.

Much simpler than C:

```c
strcmp(a, b)
```

---

## Automatic Memory Management

Like `std::vector`, `std::string` uses RAII.

Example:

```cpp
void f() {
    std::string s = "hello";
}
```

When the function ends:

- string destructor runs
- memory released

No `free()` required.

---

## Performance

`std::string` is efficient because:

- dynamic resizing
- contiguous memory
- small-string optimization (SSO)

SSO means small strings may be stored **inside the object itself**, avoiding heap allocation.

---

## Comparison with C Strings

| Feature | C string | `std::string` |
|---------|----------|---------------|
| Null terminator | required | hidden internally |
| Memory management | manual | automatic |
| Concatenation | `strcat` | `+` |
| Length | `strlen` | `.size()` |
| Safety | low | high |

---

## Connection to C knowledge

C-style string:

```c
char* name = "Alice";
```

Modern C++:

```cpp
std::string name = "Alice";
```

Instead of:

```
strlen
strcpy
strcat
strcmp
```

we use:

```
size()
+=
+
==
>
<
```

Much cleaner.

---

## Takeaway

> - `std::string` replaces C-style strings.  
> - It manages memory automatically.  
> - It grows dynamically.  
> - It integrates naturally with C++ containers and algorithms.  
> - It avoids many buffer overflow risks of C strings.
