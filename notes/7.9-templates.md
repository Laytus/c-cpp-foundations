# Module 7.9 – Templates (Intro)

### Learning Goals

- Understand what **templates** are

- Understand how the **STL uses templates**
- Learn to write **simple function templates**
- Learn to write **simple class templates**

---

## The Core Problem

In C, if we want the same function for multiple types, we must duplicate code.

Example:

```c
int max_int(int a, int b) {
    return a > b ? a : b;
}
```

Now for doubles:

```c
double max_double(double a, double b) {
    return a > b ? a : b;
}
```

Now for `floats`:

```c
float max_double(float a, float b) {
    return a > b ? a : b;
}
```

This is **code duplication**.

---

## The C++ solution: Templates

Templates allow writing **generic code**.

Example:

```cpp
template <typename T> 
T max(T a, T b) {
    return a > b ? a : b
}
```

Usage:

```cpp
max(3, 5)      // int
max(3.2, 7.4); //double
```

The compiler generates the correct version automatically.

---

## How Templates work

Templates are **compile-time code generators**.

Example call:

```cpp
max(3,5);
```

Compiler generates:

```cpp
int max(int a, int b) {
    return a > b ? a : b
}
```

Another call:

```cpp
max(2.5, 7.8);
```

Compiler generates:

```cpp
double max(double a, double b) {
    return a > b ? a : b
}
```

This is called:

> template instantiation

---

## Template Syntax

Basic structure:

```cpp
template <typename T>
return type function name(parameters)
```

Example:

```cpp
template <typename T>
T square(T x) {
    return x * x;
}
```

Usage:

```cpp
square(4);   // int
square(2.5); // double
```

---

## `typename` vs `class`

Both work:

```cpp
template <typename T>
```

or

```cpp
template <class T>
```

They mean the same thing here.

Modern style usually uses:

```
typename
```

---


## Multiple Template Parameters

Example:

```cpp
template <typename T, typename U>
auto add(T a, U b) {
    return a + b;
}
```

Usage:

```cpp
add(3, 4.5);
```

Return type deduced automatically.

---

## Template Classes

Template also work for classes.

Example: *a simple container*.

```cpp
template <typename T>
class Box {
public:
    T value;
}
```

Usage:

```cpp
Box<int> a;
Box<double> b;
```

Compiler generates:

```
Box<int>
Box<double>
```

as separate types.

---

## Real Example: `std::vector`

`std::vector` is actually a **template class**.

Conceptually:

```cpp
template <typename T>
class vector {
    ...
}
```

Usage:

```cpp
std::vector<int> v;
std::vector<double> v2;
std::vector<std::string> v3;
```

Each types produces a specialized version.

---

## Why Templates are powerful

Templates allow:

- generic containers
- generic algorithms
- zero-cost abstractions

Example:

- `std::vector<T>`
- `std::sort<T>`
- `std::optional<T>`
- `std::unique<T>`

This is the basis of the **STL**.

---

## Example: Generic Swap

Without templates:

```c
void swap_int(int* a, int* b);
void swap_double(double* a, double* b);
```

With templates:

```cpp
template <typename T>
void swap_values(T& a, T& b) {
    T tmp = a;
    a = b;
    b = tmp;
}
```

Usage:

```cpp
int a = 5;
int b = 10;

swap_values(a, b);
```

Works for:

- `int`
- `double`
- `string`
- custom types

---

## Compile-Time vs Runtime Polymorphism

Templates use **compile-time polymorphism**.

Meaning:

> type chosen at compile time

No runtime overhead.

Contrast with:

> virtual functions

which use runtime dispatch.

This is why templates are popular in **high-performance libraries**.

---

## Example from Quant/ML

Matrix library:

```cpp
template <typename T>
class Matrix {
    std::vector<T> data;
}
```

Usage:

```cpp
Matrix<double>
Matrix<float>
Matrix<int>
```

The compiler generates optimized versions for each type.

---

## A Key Rule

Templates are compiled **only when used**.

Example:

```cpp
template <typename T>
T cube(T x) {
    return x*x*x;
}
```

If we only call:

```cpp
cube(5);
```

The compiler generates:

```cpp
cube<int>
```

But not:

```cpp
cube<double>
```

---

## Where Templates must be defined

Templates are usually implemented in **headers**.

Reason:

> compiler must see full definition to generate code

Example:

```
vector.h
```

contains the full template implementation.

---

## Connection to C kownledge

In C, we sometimes simulate generics using:

- `void*`
- macros

Example:

```c
void* data;
```

This is unsafe.

Templates give:

- type safety
- no runtime overhead
- compile-time checks

## Takeaway

> - **Templates** allow writign **generic code** that works for *many types*.  
> - They eliminate code duplication.  
> - They enable generic containers and algorithms.  
> - They generate optimized code at compile time.  
> - They form the foundation of the STL.
