# `std::vector`

### Learning Goals

- Understand what `std::vector` is
- Learn how vectors manage dynamic memory
- Understand **size vs capacity**
- Learn how to add and access elements
- Learn how vectors replace manual dynamic arrays from C

---

## The Core Idea

A `std::vector` is a **dynamic array container** from the C++ Standard Library.

Example:

```cpp
std::vector<int> v;
```

This creates a container capable of storing a **variable number of integers**.

Unlike C arrays:

```c
int arr[10];
```

vectors can *grow and shring dynamically**.

---

## Why `std::vector` exists

In C, dynamic arrays require manual memory management.

Example:

```c
int *arr = malloc(n * sizeof(int));

arr = realloc(arr, new_size * sizeof(int));

free(arr);
```

Problems:

- manual memory handling
- easy to leak memory
- easy to misuse `realloc`
- ownership unclear

`std::vector` solves these problems by managing memory automatically.

---

## Basic Vector Declaration

Example:

```cpp
std::vector<int> v;
```

This creates an **empty vector**.

#### Vector with initial size

```cpp
std::vector<int> v(5);
```

This creates:

```
[0, 0, 0, 0, 0]
```

Five integers initialized to zero.

#### Vector with initial values

```cpp
std::vector<int> v = {1, 2, 3, 4};
```

Memory:

```
[1, 2, 3, 4]
```

---

## Vector Memory Model

Vectors store elements in **contiguous memory**.

Conceptually:

```
vector object
    |
    | pointer
    V

heap memory
[1][2][3][4]
```

This is similar to C arrays.

Because of this:

> vector elements are cache-friendly

---

## Size vs Capacity

Vectors track two important values.

#### Size

Number of elements currently stored.

```cpp
v.size()
```

Example:

```
vector = [1,2,3]

size = 3
```

#### Capacity

Total allocated storage.

```cpp
v.capacity()
```

Example:

```
vector = [1,2,3]

capacity = 8
```

Meaning the vector has room for **8 elements without reallocating**.

---

## Adding Elements

#### `push_back`

Adds an element to the end.

Example:

```cpp
std::vector<int> v;

v.push_back(10);
v.push_back(20);
v.push_back(30);
```

Vector becomes:

```
[10, 20, 30]
```

---

## Accessing Elements

#### Index operator

```cpp
v[0]
v[1]
v[2]
```

Example:

```cpp
std::cout << v[1];
```

Output:

```
20
```

#### Safe access

```cpp
v.at(1)
```

Difference:

- `v[1]` → no bounds checking
- `v.at(1)` → throws exception if invalid

---

## Iterating over a Vector

#### Classic loop

```cpp
for (size_t i = 0; i < v.size(); i++) {
    std::cout << v[i];
}
```

#### Range-based loop

```cpp
for (const auto& x : v) {
    std::cout << x;
}
```

No copying, safe iteration.

---

## Modifying Elements

```cpp
for (auto& x : v) {
    x *= 2;
}
```

Vector:

```
[1,2,3]
```

Becomes:

```
[2,4,6]
```

---

## Vector Resizing

Vector grow automatically.

Example:

```cpp
std::vector<int> v;

v.push_back(1);
v.push_back(2);
v.push_back(3);
```

If `capacity` runs out:

- vector allocates larger memory block
- copies existing elements
- releases old memory

This is why `push_back` is usually **amortized `O(1)`**.

---

## Reserving Memory

If we know the expected size:

```cpp
v.reserve(1000);
```

This avoids repeated reallocations.

Very useful in performance-sensitive code.

---

## Removing Elements

#### Remove last element

```cpp
v.pop_back();
```

Example:

```
[1,2,3]
```

Becomes:

```
[1,2]
```

---

## Clearing the Vector

```cpp
v.celar();
```

Result:

```
size = 0
capacity unchanged
```

---

## Vector vs C Arrays

| Feature | C Array | `std::vector` |
|---------|---------|---------------|
| Dynamic size | no | yes |
| Memory safety | manual | automatic |
| Bounds checking | none | optional |
| Automatic | no | yes |
| Standard library integration | no | yes |

---

## Performance

`std::vector` is extremely efficient.

Reasons:

- contiguous memory
- cache-friendly layout
- amortized constant-time growth

In practice, it performs similarly to **C dynamic arrays**.

---

## When to use `std::vector`

We use vector when we need:

- dynamic arrays
- fast iteration
- contiguous memory
- automatic memory management

Vectors are the **default container** in modern C++.

---

## Connection to C knowledge

The C dynamic array:

```c
int *arr = malloc(n * sizeof(int));
```

Modern C++ equivalent:

```cpp
std::vector<int> arr(n);
```

The C resizing pattern:

```c
arr = realloc(arr, new_size);
```

Modern C++:

```cpp
v.push_back(value);
```

---

## Takeaway

> - `std::vector` is a *dynamic array container*.  
> - It manages memory automatically.  
> - Elements are stored in *contiguous memory*.  
> - `size` is the *number of elements*.  
> - `capacity` is the *allocated storage*.  
> - `push_back` *appends elements*.  
> - Range-based loops work naturally with vectors.
